# Lessons

- When delegated scope is clarified, treat the latest explicit requirement as canonical and verify the target route before implementation.
- When placement matters, verify the exact public route and section before release; an episode player requested “on the homepage” is not satisfied by an episode-archive implementation.
- Before adding a podcast embed or platform icon, verify the exact show and episode URLs; similarly named public listings are not a safe substitute. If the platform listing does not exist, label that state honestly and use the owned audio source.
