LMCache multiprocess/distributed mode opens an unauthenticated ZeroMQ ROUTER socket (default port 5555, no CURVE/ZAP/auth); one crafted DEALER message hits pickle.loads as the LMCache process user — and official container images run as root. Henry's local-first audience is exactly who this warns.
