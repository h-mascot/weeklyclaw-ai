GPT modes

Strict mode and native Codex as harness

1) Strict mode
agents.defaults.embeddedPi.executionContract = "strict-agentic"
  • This tells GPT-5.x to keep working: read more code, call tools, make changes, or return a real blocker instead of stopping at “here's the plan.”
2) Native Codex as the OpenClaw harness
plugins.entries.codex.enabled = true
agents.defaults.model = "codex/gpt-5.4"
agents.defaults.embeddedHarness = {
  runtime: "codex",
  fallback: "none"
}
  • Codex owns threads, resume, compaction, app-server execution.

Memory

Memory is still the strategic bet

  • Active memory gives OpenClaw a dedicated memory sub-agent right before the main reply, so ongoing chats can automatically pull in relevant preferences, context, and past details without making users remember to manually
  • Dreaming and recall systems got refined
  • More work on session recovery and compaction resilience
  • The product is clearly being shaped around long-horizon usefulness
