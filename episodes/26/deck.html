SEG 1 · OPEN UNDER REVENUE THRESHOLDS

Qwen ships a Max-class checkpoint, then prices "open" at $50M.

On August 14, Qwen released Qwen3.8-2.4T-A95B to Hugging Face: 2.446T BF16 parameters, 95B active per token, 92 layers, 512 routed experts, 262,144 native context extensible to ~1.01M. The repository is ungated, 224 files, ~4.89 TB.

Headline artifact

2,446,182,725,504 BF16 parameters. 95B active per token. 224 files, 4.89 TB. HF repo live, ungated. 6,381 downloads, 950 likes at retrieval.

  • Apache… no — custom Qwen license
  • Text-only with mandatory reasoning
  • OpenRouter: $2 input / $6 output per M tok

Downloadable vs hosted

The downloadable release is text-only with mandatory reasoning. Hosted Qwen3.8-Max adds vision, non-thinking mode, built-in tools, default 1M context.

  • Downloadable: text + thinking only
  • Hosted Max: vision + tools + non-thinking
  • Vendor-run benchmarks; not independently reproduced

Two revenue thresholds

License A: products above 100M MAU or $20M monthly revenue must use prominent model naming. License B: model-service or AI work-assistant companies above $50M revenue in any consecutive 12-month period require a separate Qwen license.

  • Threshold A: $20M / month → naming
  • Threshold B: $50M / year → separate license
  • Not Apache 2.0; not feature-identical to Max
"If the weights are downloadable but require five terabytes, serious inference infrastructure, and a separate license once your AI assistant reaches $50 million, did frontier capability become open — or merely inspectable?"

SEG 2 · SUPERVISORY JUDGMENT

A 27B scientist directs GPT-5.5 like a scientist.

Inherent's Faraday is post-trained on Qwen3.6-27B and builds a scientific agent that calls GPT-5.5 Codex as a coding worker, rather than encoding scientific workflow in a large hand-built multiagent harness.

REPLICA TASK ANATOMY

310 figure-replication tasks

Across 100 ML and AI-for-science papers. 242 training, 68 test. Each agent receives a paper with one results figure redacted, a 60-minute deadline, internet access, and 1/7 of an H200 GPU.

  • 242 train / 68 test tasks
  • 60 min deadline per task
  • 1/7 H200 GPU per agent
  • 5 ordinary tools + resumable Codex CLI wrapper
EVALUATION LOOP

Faraday uses Codex. Codex also judges.

Long-horizon GRPO, per-task rubrics, three judge samples, turn-level credit assignment. The paper reports Faraday beating Claude Opus 4.8 and GPT-5.5 on 60% of held-out AI-for-science tasks, averaging 6% above Claude and 8% above Codex on the test split.

  • 60% win rate on held-out AI-for-science
  • +6% Claude / +8% Codex on test split
  • 29 / 41 human-preferred rollouts
  • Caveat: author-run, no public weights

Why this is not "27B vs frontier"

The 27B does not outperform the frontier model alone — it outperforms it by calling it. The same Codex model also serves as the rubric judge. The human study deliberately sampled cases where the automated judge saw a strong Faraday advantage.

"If a 27B supervisor can direct a model two orders of magnitude larger, should we spend the next dollar on a smarter worker — or on training the judgment that decides what the worker should do?"

S3 · HENRY
SEG 3 · WALL-CLOCK BUDGET

Cerebras ships three wafers, DFlash 2 ships an open drafter.

Agent intelligence is now constrained by wall-clock time as much as model quality. Cerebras attacks the bottleneck with rack-scale hardware; Inco attacks it in decoding software with a downloadable drafter.

HARDWARE SCALE · CS-4

Three WSE-3 Turbo wafers.

CS-4 combines three WSE-3 Turbo wafers: 750 PFLOPS, 129.6 PB/s memory bandwidth, 7.2 Tb/s I/O, two-microsecond wafer-to-wafer latency. First shipments begin this quarter.

  • 750 PFLOPS · 129.6 PB/s memory BW
  • 2 μs wafer-to-wafer latency
  • >4,400 tok/s/user on GPT-OSS-120B
  • Up to 30× production GPU, up to 10× CS-3/W
  • Caveat: vendor-reported
SOFTWARE DRAFTING · DFLASH 2

4.80 accepted tokens per step.

DFlash 2 uses a selector plus local convolution to improve parallel speculative drafts while preserving the target model's output under lossless rejection sampling. The released Qwen3.8-27B drafter averages 4.80 accepted tokens vs 4.28 for native MTP and 3.62 for community DSpark.

  • 4.80 vs 4.28 MTP vs 3.62 DSpark
  • 2.7–3.4× SGLang throughput vs AR
  • 16–25% more accepted output / pass
  • Apache-2.0 drafter on Hugging Face
  • vLLM + llama.cpp PRs: OPEN
"If an agent gets 30 times more tokens in the same minute, should we make the answer arrive faster — or spend the entire gain on more checking before anyone sees it?"
VENDOR-RUN: Cerebras throughput and Inco benchmark numbers were not independently reproduced. vLLM and llama.cpp integration PRs remain open. Henry's M5 128 GB Mac Pro result of 76.8 tok/s is first-hand host signal, not a neutral benchmark.

SEG 5 · SPEND BOUNDARY

Agents pay mid-task, but the model never holds the key.

AWS Bedrock AgentCore Payments moved from May preview to GA on August 18. BNB Agent Studio v2 ships an Altana wallet with onchain permissions. Two distinct designs for the same control plane.

AWS · AGENTCORE PAYMENTS GA

Payment like any other agent action.

Agents discover and pay for APIs, MCP servers, inference, and content through x402 or Stripe and Tempo's MPP. Coinbase and Stripe Privy provide stablecoin wallets; raw developer credentials stay in AgentCore Identity Secrets Manager; short-lived tokens instruct wallet operations.

  • Per-session max spend + expiry below the agent loop
  • x402 upto ceilings for metered usage
  • CloudWatch logs, spans, dashboards
  • Claude Code, Kiro, Codex skills + Strands / LangGraph / OpenClaw integrations
BNB · ALTANA WALLET

Permissions onchain, keys with the builder.

BNB Agent Studio v2 ships an Altana wallet where scoped session keys carry spending limits, allowlists, and time bounds registered onchain. Revocable without giving the agent the private key.

  • Spending limits + allowlists + time bounds
  • Registered onchain
  • Revocable without the agent holding the key
  • Caveat: not independently audited
"When an agent can pay for the next API call without asking, which layer should own the veto — the model, the workflow, the wallet, or a policy the agent cannot rewrite?"

The rule, three times

Probabilistic reasoning proposes a purchase. Deterministic infrastructure decides whether money can move. The model never holds the key.

04 / HOT TAKE · 3 MIN
Hot take · 3 min · distinct from every news segment

Provenance is involvement, not authorship.

Anthropic's text watermark changes the source of randomness in low-stakes word choices. A positive detection means Claude likely processed some of the content — not that Claude authored it.

COVERAGE MAP

Where the watermark works.

Detection confidence grows with passage length and available interchangeable word choices. Exact facts, code, proofreading, and heavy edits provide little room for a mark.

  • Long prose: stronger signal
  • Translation: more markable
  • Facts + code + light edits: sparse signal
  • Short passages: too little entropy
PRODUCTION-LAYER FIX

Signed receipts, not watermark guesses.

The defensible position is to stop pretending detectors settle attribution. Start designing workflows where the agent's identity is a content-keyed, hash-chained, timestamped receipt — not a guess about which sampler touched it.

  • Involvement ≠ authorship
  • Detector API: coming soon
  • C2PA file credentials are a separate path
  • The model becomes the new plausible deniability
"What decision is the detector safe enough to make?"

05 / CLOSE
One to watch + where to follow

See you next Friday.

The closing conditions

Stripe–OpenRouter is signed, not closed. If the deal closes before August 28, the gateway and wallet ship as one company and the neutrality promise becomes a one-quarter-old commitment under audit. If the close slips, the test shifts to whether the OpenRouter catalog and pricing stay stable through the regulatory tail.

The speed arms race

Cerebras CS-4 begins shipping this quarter. vLLM and llama.cpp DFlash 2 pull requests are open. When the upstream serving stacks merge the drafter, every operator's effective throughput jumps — and so does every operator's wall-clock budget for reasoning.

The detector API

Anthropic says the Claude detector is "coming soon." Until it ships, the watermark is a triage signal, not an authorship verdict. The production-layer fix is signed receipts — identity, authorization, timestamp — that do not depend on which sampler touched the text.
