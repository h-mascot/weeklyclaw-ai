06 — Seminar · Part 1
Part One — The Concept

What Is a Dark Factory?

Manufacturing Origin

A lights-out factory runs entirely without humans. Robots build the product, do QC, move inventory. Nobody turns the lights on because nobody's there. Toyota has them.

The Software Version

AI agents write code, review PRs, merge changes, deploy. You define what to build upfront, set agents in motion, come back to a finished product.

The Productivity Numbers Are Real

Peter ran 10 parallel sessions during peak OpenClaw dev. Down to 5–6 now — not because he pulled back, but because the loops got faster.

🏭

The Promise

No bottlenecks. No context-switching. No review queue. 24/7 throughput.

So why not go all the way?

06 — Seminar · Part 2
Part Two — The Planning Assumption

The Curved Path Problem

"Dark factory in a way also means I come up with everything I want to build in the beginning. And I just don't think you can build good software in that way. The way to the mountain is usually never a straight line. It is very curved. Sometimes you go a little off track, and then you see something new that inspires you, you find shortcuts. Once you're at the top, you can find the optimal path, but you never walk like this."
— Peter Steinberger · AI Engineer World's Fair AMA, April 17, 2026

🌊 Building = Discovering

You ship a step, feel it, get new ideas, your prompts change. The artifact of working code gives you information that no amount of planning can generate in advance.

🚫 The Waterfall Trap

"Your first idea about the project is very unlikely going to be the final project. But if I suddenly use the waterfall model again, that will be the final project for me." The dark factory is waterfall with robots.

06 — Seminar · Part 3
Part Three — Taste

Taste Is the Moat

⬇️ The Low Bar

Doesn't stink like AI. No overlong responses. No em-dashes. No purple gradient UI. No left-side color borders. No writing that's technically correct but has no personality. Clearing the low bar is table stakes.

⬆️ The High Bar

When you start a session, sometimes OpenClaw roasts you. Nobody filed a ticket for that. That's someone deciding a personal AI agent should feel like it has a personality — not like a search engine. The difference between software that works and software someone loves.

"Everything is a prompt away now. Every feature, every idea — someone can spec it in two sentences and an agent will build something. The constraint is no longer 'can we build it.' It's knowing which things to build, in what order, and what to throw away."
— The editorial function that dark factory outsources
Design (skill #1) Saying No (skill #2) Judgment > Throughput
🦞
Seminar — One Question to Take With You
As throughput keeps increasing — as the loops get faster, as more of the review and testing and deployment gets automated — where does taste survive in that chain?
Not "slow down." Rethink what human review is actually for — and build tools that let us exercise judgment at the right level of abstraction, not just the line level.
Open Problem Ours to Work On
