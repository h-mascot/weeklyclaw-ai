What this episode covers

  • YC QM open-sourced the operating layer it claims to run its batch on.
  • Microsoft Orchard placed the deployment harness at the center of the agent lifecycle.
  • Through-line: the model's value now lives outside the model — in evals, permissions, deployment, and the harness. Signal From Outside stayed as the permanent anchor segment. Sponsors: Herald Labs and Heritage Telecom.
