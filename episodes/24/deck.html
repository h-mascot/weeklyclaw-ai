Segment 3 · Self-editing runtime · PINNED BY ANDY
S3 · 5:30 · Henry

Prime Agent: self-editing runtime meets disclosed reward hacking

Aug 5 open-source release — MIT-licensed, 2,916 stars. Two abstractions: Recursive Language Model + Continual Harness. System prompt immutable; /refine rewrites prompt notes, memory, skills, subagent specs with rollback.

Runtime design
  • Persistent IPython REPL exposes context, tools, subagents as functions
  • Daemon owns sessions; workers recover from JSONL + kernel snapshots
  • Persistent children survive compaction, can be messaged later
  • Autonomous mode: goals, heartbeats, turn / token / time limits, completion gate

Open the box. Test whether it can still close.

Henry's proposition

Audit like a benchmark

By end of Q3, agent-infrastructure claims get audited like benchmark claims — no open repo with a license file and a star count, no headline.

Andy's pushback

The box can be open and still lose the ability to close

Prime shipped the repo and the disclosure together — the bar is already moving. But /refine rewrites skills and memory. A control plane that survives self-editing is a different kind of open.
