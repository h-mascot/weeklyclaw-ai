# Weekly Claw production skills

These skills describe the editorial master, thumbnail and release workflow:

- `weekly-claw-episode-editor`: ingest, edit, render and verify an episode.
- `thumbnail-skill`: create and independently review episode artwork.
- `weekly-claw-youtube-publisher`: release handoff, YouTube checks and distribution. Community distribution is part of this publisher; see `references/community-distribution.md` and `references/distribution-checklist.md`.

These are public, portable extracts of the active canonical instructions reviewed on 2026-11-13. They preserve the production and release gates, but generalize machine-specific ownership, routes, account recovery and private destination details.
