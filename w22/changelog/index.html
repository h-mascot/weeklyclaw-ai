Developer Experience, opinion

A repair-heavy week is healthy at this scale
DX review

Everything on this slide is opinion. The facts sit on slides 2 to 8.

Fix to feature ratio

1,424 fix commits against 80 feat commits reads as deliberate debt paydown. I trust that more than a feature week.

Recovery over novelty

Every stable release this week makes an existing install harder to strand. That is the work people running it notice.
