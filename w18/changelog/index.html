Channels got less brittle

Telegram and WhatsApp changes point at a simple operator promise: the agent can produce rich work, and the channel should not flatten it into mush.

Rich delivery

Tables, lists, expandable blockquotes, intentional line breaks, stickers, media, and CLI-backed replies get preserved more faithfully.

Thread and account scope

DM sends, thread replies, Mattermost context, Slack final replies, and Discord action handling were tightened.

Why it matters

A failed preview or stripped format should not turn a useful agent run into a support mystery.

Agent runs recovered more often

The release notes keep circling the same concern: partial turns, interrupted sessions, yielded subagents, compaction, and replay all need visible endings.

Runtime recovery

Thinking-only retries, duplicate-hook prevention, partial JSON repair, truncated-response detection, and restart abort handling reduce dead air.

Generated work

Media completions, auto-reply final messages, and yielded subagent pauses make long-running agent work easier to reason about.

Operator effect

More runs end with an artifact, a diagnostic, or a clear failure mode instead of a ghost.

DX review: failure modes became legible

Week 18 is not just feature velocity. It is work on the places agents usually embarrass themselves: context, delivery, replay, and status.

  • Cron status reports SQLite storage paths instead of stale legacy job files.
  • CLI usage-error exits stay classified as usage failures, not fake successes.
  • Session history repair and compaction usage preservation keep debugging evidence alive.
  • Credential-aware usage footers make budget and route limits more visible.

Signal map: autonomy with receipts

The strongest thread is the same one Weekly Claw keeps returning to: agents need proof loops, not just bigger prompts.

Input

Issues, PRs, channel threads, and release notes become promptable operating surfaces.

Loop

Screenshots, tests, status, usage, replay, and delivery receipts close the loop.

Output

A human can inspect what changed, what failed, and what shipped without reverse-engineering the agent.
